Overview

The Docker Cleanup Playbook is a battle-tested shell script designed for developers drowning in unpruned volumes, dangling images, and stopped containers that eat up SSD space. It inspects your local Docker environment and generates a precise, customized cleanup script without executing anything blindly. It helps busy software engineers reclaim gigabytes of disk space safely and transparently, without the anxiety of accidentally wiping a database container they actually need.

Use cases

  • Freeing up hundreds of gigabytes of disk space on a developer laptop when Docker suddenly warns you that storage is critically low.
  • Cleaning up abandoned test environments and dangling build cache layers generated by CI pipelines or local testing.
  • Auditing what Docker actually plans to delete before running a destructive command on a shared development server.

How to use it

  1. Download the standalone script file to your local machine.
  2. Grant execution permissions using chmod +x docker-cleanup.sh.
  3. Run the script in your terminal to inspect the generated cleanup plan and copy the commands you want.
